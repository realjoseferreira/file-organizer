# File Organizer

A simple command-line tool built with Python to automatically organize files into folders based on their extensions.

This project was created as a practical software development exercise focused on file handling, command-line arguments, error handling, logging and clean project organization.

---

## Features

- Organizes files by category
- Creates folders automatically
- Supports custom folder paths
- Prevents file overwriting
- Generates logs with timestamps
- Shows a final organization summary
- Provides command-line help with `--help`

---

## File Categories

The tool currently supports the following categories:

| Category | Extensions |
|---|---|
| Images | `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp` |
| Documents | `.pdf`, `.docx`, `.txt` |
| Spreadsheets | `.xlsx`, `.csv` |
| Videos | `.mp4`, `.mov`, `.avi` |
| Audios | `.mp3`, `.wav` |
| Compressed | `.zip`, `.rar`, `.7z` |
| Others | Any unsupported extension |
